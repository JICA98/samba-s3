Required lease fields: role/run ID, device pseudonym, stable private physical ID, current serial, canonical ADB host/server identity, OS lock path and holder, runner handle or PID, issue/heartbeat/expiry times, scenario and command policy. The tester neutralizes controls when connected, stops only test-owned recorders, checks whether a native save writer is active, and releases the lease only after safe state is observed.
