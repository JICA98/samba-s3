# Archived assembler experiments

Exploratory sources from before the tested Fast LLVM implementation. They are not build inputs. `patch_spu_fast.py` edits a checkout in place and preserves an older prototype; do not run it against the v5 core. Generated object files remain local and are ignored. The original shared-checkout changes are preserved in `docs/gow3-13r/fastllvm-v5/superseded/`.
